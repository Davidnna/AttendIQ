# AttendIQ — Brand Guidelines (Initial)

## Brand name
**AttendIQ**

## Tagline
**Presence, verified.**

## Brand positioning
AttendIQ is a clear, dependable attendance-management platform designed for educational environments. It brings attendance workflows, identity verification and reporting into one web-based experience.

## Brand attributes
- Trustworthy
- Precise
- Accessible
- Modern
- Academic, without looking institutional or bureaucratic

## Primary colour palette

| Token | Hex | Use |
|---|---|---|
| Midnight Navy | `#101A33` | Primary brand colour, headers, navigation |
| Signal Teal | `#19B89F` | Primary action, verification, positive status |
| Cloud Mist | `#F5F7FA` | Page background |
| White | `#FFFFFF` | Surfaces and cards |
| Slate | `#53627A` | Secondary text |
| Amber | `#F2B85B` | Caution and attention states |
| Error Red | `#C94C4C` | Destructive/error states |

## Typography
- Display/headings: Manrope, with system sans-serif fallback.
- Interface/body: Inter, with system sans-serif fallback.
- Use sentence case for interface labels.
- Keep paragraphs short and use clear, descriptive headings.

## Logo
The initial logo combines a scan-frame motif with a verification check. Use the horizontal logo on light backgrounds. Use the standalone mark for compact placements such as the favicon and mobile navigation.

Do not stretch, recolour arbitrarily, add effects, or place the logo on a low-contrast background.

## Voice and writing
- Direct, calm and precise.
- Prefer “Verify attendance” over vague labels such as “Proceed”.
- Explain errors without exposing stack traces, secrets, server paths or configuration.
- Never claim that facial recognition is infallible.
- Explain when a feature is a prototype or not yet available.

## Product disclaimer
The current release is a software prototype. Do not imply institutional endorsement, regulatory certification or production-grade biometric assurance.
